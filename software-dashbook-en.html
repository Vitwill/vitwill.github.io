DashBook

Personal Digital Notebook-Organizer with AI Assistant

About the App

DashBook is a personal digital notebook-organizer designed in the aesthetic style of a classic grid notebook with margins. The application combines task planning, project management, a calendar of important dates, a personal diary, and an interactive AI assistant in a single convenient interface.

Type Web Application / Organizer
Platform Browser (Web)
Status Ready to Use

App Screenshots

Main Sections

📅 Tasks & Meetings

  • Create, edit, and mark completed tasks
  • Set priorities, deadlines, and categories
  • Meeting calendar with date, time, and location
  • Notes for each meeting

🗂️ Projects

  • Organize large-scale goals and work projects
  • Break projects into subtasks
  • Track overall progress
  • Manage project statuses

📝 Notes

  • Quick notepad for ideas and lists
  • Save text notes and links
  • Convenient card grid layout
  • Quick search and editing

✨ Events & Dates

  • Plan important events and holidays
  • Birthday registry with automatic countdown
  • Confetti celebration effect on the event day
  • Descriptions and reminders

📔 Diary

  • Daily personal entries and reflection
  • Mood of the day selection
  • Record thoughts and events with date tags
  • History of entries with review option

⚙️ Profile & Settings

  • Upload user avatar
  • Edit personal information
  • Manage application settings
  • Switch interface language
